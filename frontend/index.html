📊 Microsoft Power BI Live Integration

Directly connect Power BI Desktop to your live FastAPI backend or export standardized ticket datasets for executive dashboards.

📥 Download CSV Dataset for Power BI

Method 1: Direct Web API REST Connector

In Power BI Desktop, select Get Data ➔ Web and paste the endpoint URL below. Your dashboard will refresh with real-time tickets and predictions automatically.

http://localhost:8000/api/export/powerbi-json

Method 2: Power Query (M-Code) Connector

Open Power Query Advanced Editor and paste this query to automatically ingest and expand all ticket columns:

let Source = Json.Document(Web.Contents("http://localhost:8000/api/export/powerbi-json")), DataList = Source[data], TableData = Table.FromList(DataList, Splitter.SplitByNothing(), null, null, ExtraValues.Error), Expanded = Table.ExpandRecordColumn(TableData, "Column1", {"id", "ticket_code", "customer_name", "category", "sentiment_label", "priority", "status", "created_at"}) in Expanded

📐 Pre-Engineered Power BI DAX Measures

Resolution Rate %
Resolution Rate % = DIVIDE( CALCULATE(COUNTROWS('Tickets'), 'Tickets'[status] = "Resolved"), COUNTROWS('Tickets'), 0 ) * 100
Negative Sentiment Rate %
Negative Sentiment Rate % = DIVIDE( CALCULATE(COUNTROWS('Tickets'), 'Tickets'[sentiment_label] = "Negative"), COUNTROWS('Tickets'), 0 ) * 100
Urgent Backlog Count
Urgent Backlog = CALCULATE( COUNTROWS('Tickets'), 'Tickets'[priority] = "Urgent", 'Tickets'[status] <> "Resolved" )
